# 站点统计增强

> 访客来源、热门内容与转化漏斗，比基础报表更细。

## 功能特性

| 模块 | 说明 |
|------|------|
| 访客来源 | 搜索引擎 / 直链 / 外链来源分布 |
| 热门内容 | 按浏览量 / 互动量排行 |
| 转化漏斗 | 访客 → 注册 → 评论 / 关注的转化链路 |

## 安装

1. 先安装依赖插件 **SEO 优化**（免费）；
2. 后台「插件商城」搜索「站点统计增强」；
3. 点击「购买并安装 · ¥49」，完成支付后自动激活。

## 配置说明

安装后可在「我的插件 → 打开设置」中配置统计口径：

- 统计范围：全部 / 仅登录用户；
- 热门内容窗口：7 天 / 30 天 / 全部。

## FAQ

**Q：为什么必须依赖 SEO 优化？**
A：转化漏斗需要帖子的收录与跳转数据，SEO 优化提供底层来源识别。

**Q：数据存在哪里？**
A：全部在本站数据库内，不上传第三方，可随时导出。
