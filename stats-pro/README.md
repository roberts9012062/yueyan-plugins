# 站点统计增强

> 访客 PV/UV 计数、热门内容排行与后台统计面板，比基础报表更细。免费。

## 功能特性

- **PV/UV 计数**：按日统计页面浏览与独立访客（访客标识按日去重），今日/昨日/累计一目了然；
- **热门内容排行**：帖子页浏览自动上报，后台 Top10 排行；
- **后台面板**：侧栏「插件 → 站点统计」进入仪表页；
- **管理员排除**：站长自己的访问默认不计数（可关）。

## 安装

后台「插件商城」找到「站点统计增强」→「免费安装」自动激活。

## 配置说明

| 设置项 | 说明 | 默认 |
|--------|------|------|
| 管理员访问不计数 | 开启后站长浏览不污染统计 | 开 |

## 技术说明

- 前台上报走宿主公开桥接 `POST /api/v1/stats/hit`（访客无需登录，每 IP 限流）；
- 访客标识为浏览器 localStorage 随机 ID（服务端按日去重算 UV，不采集可识别信息）；
- 计数内存累加、节流落盘（`data/plugins/stats-pro/stats.json`），日明细保留 90 天。

## FAQ

**Q：统计与后台自带「数据报表」有何区别？**
A：报表看站点内容指标（发帖/评论量等）；本插件聚焦访客流量（PV/UV）与内容热度排行，两者互补。
