# 精品导航（nav-links）

收藏你喜爱的精品站点，前台一键展示。后台增删改查 + 分类/标签筛选 + AI 智能分类 + 自动抓取站点图标；前台精美导航页访客可看；另开放数据接口供浏览器插件同步。

## 功能特性

- **后台收藏管理**：站点增删改查、手动排序（上移/下移）、按分类筛选、按标签筛选、关键词搜索
- **分类/标签独立管理**：「管理分类」「管理标签」弹层支持添加（可预置）、行内重命名、删除——重命名与删除自动级联更新全部站点；前台只展示有站点的分类/标签
- **表单字段**：站点地址（URL）、网站名字、分类（必填）、标签（可选，最多 10 个）、站点简介、**可见性（开放/私有，默认开放）**
- **AI 全自动识别**：只填一个 URL，失焦即自动抓取页面信息并由 AI 生成**网站名字、分类、标签、简介**四项（也支持「✨ AI 识别」按钮重跑）；模型取自站点已配置的 AI 供应商（需在后台「AI 设置」配置）；页面抓取失败时自动降级为按 URL 推断
- **自动抓取图标**：添加地址后自动抓取站点 favicon（根路径 → 页面 `<link rel="icon">` 声明 → 图标服务兜底），内嵌存储展示，不依赖外部资源
- **私有导航**：精品导航页顶部「🌐 公开导航 / 🔒 私有导航」页签切换（不单独占据前台导航入口）；后台「🔒 私有设置」可切换访问方式——**仅自己可见**（站长登录态直通）或**密码访问**（访客输入访问密码解锁，7 天免重复输入；密码哈希存储，修改密码后旧解锁自动失效）；私有数据响应不缓存
- **前台精美导航页**：前台头部导航出现「精品导航」入口，访客无需登录即可浏览**开放**站点（私有条目不出现在公开页与其分类/标签聚合中）——顶部搜索，左侧分类菜单（含站点计数），中间导航卡片**双视图切换**（列表排列 / 九宫格排列，选择自动记忆），右侧 **3D 球形标签云**（自动旋转、悬停减速、拖动旋转、点击筛选）
- **开放接口**：安装后在后台「接口开放」页面的目录中出现「导航列表」，可在现有 Key 上勾选授权；浏览器插件凭 `X-Api-Key` 调用同步数据

## 安装方式

1. 后台「插件商城」搜索「精品导航」安装；或本地上传 `.bpk` 包（≤50MB）；
2. 安装后自动启用，前台头部导航出现「精品导航」入口（30 秒缓存窗口内生效）；
3. 后台侧栏「精品导航」进入管理页开始收藏站点。

## 配置说明

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 前台页面标题 | 导航页顶部大标题 | 精品导航 |
| 前台页面副标题 | 导航页副标题 | 收藏的优质站点 |
| 新窗口打开站点 | 前台卡片点击行为 | 开 |

私有导航相关（管理页「🔒 私有设置」弹层配置，存插件数据目录 `private.json`，密码仅存哈希）：

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 访问方式 | `仅自己可见`（站长登录态）或 `密码访问`（访客凭密码解锁） | 仅自己可见 |
| 访问密码 | 密码访问的解锁密码（6-64 位；留空保存 = 保持现有密码） | 未设置 |
| 私有页标题 / 副标题 | 前台私有导航页文案 | 私有导航 / 仅对站长与获准访客可见的收藏站点 |

## 开放接口（浏览器插件对接）

| 接口标识 | 方法 | 路径 | 说明 |
|---|---|---|---|
| `navlinks.list` | GET | `/api/v1/open/nav/links` | 全部**开放**收藏站点（名称/地址/分类/标签/简介/图标 dataURL） |
| `navlinks.private.list` | GET | `/api/v1/open/nav/private/links` | 全部**私有**收藏站点（响应结构与 `navlinks.list` 一致，仅含私有条目） |
| `navlinks.private.config` | GET | `/api/v1/open/nav/private/config` | 读取私有访问设置（`{mode, has_password, title, subtitle, count}`，不含密码材料） |
| `navlinks.private.save` | POST | `/api/v1/open/nav/private/config` | 修改私有访问设置（body `{mode, password?, title?, subtitle?}`；password 留空=不改，修改后前台旧解锁失效） |

**写入可见性**：`navlinks.save` 的每条链接支持可选 `visibility` 字段——不传或 `open`=开放（默认），`private`=私有（进入私有导航页）。

调用示例：

```js
const res = await fetch(`${siteOrigin}/api/v1/open/nav/links`, {
  headers: { "X-Api-Key": key },
});
const body = await res.json(); // {code, message, data}，code=0 成功
```

## FAQ

- **图标没抓到？** 部分站点无 favicon 或有防盗链，可点击「重新抓取图标」重试；仍失败则前台以首字母色块占位展示，不影响使用。
- **AI 识别结果不准？** AI 基于抓取到的页面标题/描述/正文摘要生成；SPA 类站点抓不到内容时会按地址推断，识别后可手动修改，或点「✨ AI 识别」重跑。
- **访客能看到导航页吗？** 可以。前台页面与数据端点均公开，无需登录；管理操作仅管理员可用。
- **私有站点会被泄露吗？** 不会。公开数据端点只输出开放条目（聚合分类/标签同样只算开放条目）；私有数据端点按「管理员登录态 / 解锁 token」鉴权且响应 `no-store`。
- **浏览器插件同步的站点进哪个页面？** 同步默认按「开放」写入公开导航页；插件端同步通道预留 `visibility` 字段，传 `private` 即可入私有页。
- **浏览器插件如何对接私有导航？** 在后台「接口开放」页面给 Key 勾选 `navlinks.private.list`（读私有数据）/ `navlinks.private.config`（读设置）/ `navlinks.private.save`（改设置）三个目录条目；同步到站点时链接带 `visibility: "private"` 即入私有页，读取私有分组走 `GET /api/v1/open/nav/private/links`。
