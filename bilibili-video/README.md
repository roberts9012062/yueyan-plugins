# B站视频

在月言博客中嵌入哔哩哔哩视频，支持 **360P ~ 1080P 清晰度选择**与高清播放。

## 功能特性

- **发帖插入**：编辑器「插入视频」粘贴 B 站地址（网页链接 / BV 号 / `b23.tv` 短链），自动解析视频信息（标题 / 封面 / UP 主 / 时长）并选择清晰度档位
- **高清播放**：站长登录 B 站后，插件用 WBI 签名解析真实 mp4 流地址（`no-referrer` 绕防盗链），帖子内嵌自研播放器播放，游客无需登录即可观看
- **清晰度可切换**：观看者可在 360P / 480P / 720P / 1080P 间切换（受登录身份限制自动降级）
- **游客自带账号**：游客在播放器上扫码登录**自己的 B 站账号**后，以自己的身份观看高清（登录态加密保存在浏览器本地，不上传服务器）
- **双通道登录**（后台）：扫码登录（推荐，稳定）+ 手机验证码登录（B 站风控要求滑块时自动提示改用扫码）+ Cookie 导入备用
- **安全**：登录密钥 AES-256-GCM 加密落盘；插件进程隔离运行

## 安装与配置

1. 后台「插件商城」安装并启用（或本地上传 `.bpk`）
2. 后台侧栏「B站视频」→ 扫码登录 B 站账号（用哔哩哔哩 App）
3. 发帖时「插入视频」粘贴 B 站地址，选择清晰度后插入

## 设置项

| 设置 | 说明 | 默认 |
|------|------|------|
| 默认清晰度 | 新插入视频的初始档位 | 1080P |
| 允许游客用站长账号看高清 | 关闭后未登录 B 站的访客最高 480P | 开 |

## FAQ

- **1080P 显示"需登录"？** 站长需在后台上传插件页扫码登录 B 站；720P 起需要 B 站登录态才能解析。
- **游客如何看高清？** 播放器右上角「扫码登录B站 · 解锁高清」，用自己的哔哩哔哩 App 扫码即可。
- **手机收不到验证码？** B 站短信接口有滑块风控，被拦截时请改用扫码登录。
