# QQ 音乐

站长用手机 QQ 扫码登录后，插件获取歌曲**真实播放地址**，前端**自研播放器**双主题播放，访客无需登录即可收听站内音乐。

## 功能特性

- **扫码登录**：手机 QQ 扫码授权（ptlogin2 协议），登录态加密落盘，重启自动恢复
- **真实播放地址**：登录态获取歌曲 mp3 直链，帖内嵌入即点即播
- **我的歌单**：拉取账号歌单（含「我喜欢」），可试播、可设为首页背景音乐
- **首页背景音乐**：开启后首页右下角悬浮播放器循环播放指定歌单，访客无感收听
- **发帖插歌**：写帖时搜索 QQ 音乐歌曲一键嵌入

## 安装方式

1. 后台「插件商城」搜索「QQ 音乐」安装，或本地上传 `.bpk`
2. 启用后访问「QQ 音乐」侧栏入口（或 `/admin/plugin-pages/qq-music/login`）
3. 用手机 QQ 扫码登录，在「我的歌单」选择首页背景音乐歌单

## 配置说明

| 配置项 | 说明 |
|---|---|
| 音质 | 播放音质：standard（标准）/ higher（较高） |
| 首页背景音乐 | 「设置」页开启后，首页右下角悬浮播放器播放所选歌单 |

## FAQ

- **为什么有些歌播放不了？** 无版权 / 需付费的曲目，QQ 接口不返回播放地址，会提示「无版权或需会员」。
- **扫码登录会过期吗？** 登录态长期有效并已加密保存；仅在 QQ 侧主动退出或异地风控时需重新扫码。
- **访客需要登录吗？** 不需要，只有站长在后台扫码一次，播放对访客完全公开。
