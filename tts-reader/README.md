# 朗读（TTS Reader）

帖子正文一键语音朗读插件：访客无需登录即可在帖子页「🔊 朗读」全文。

## 功能特性

- **访客可听**：宿主提供公开桥接端点，匿名访客也能合成与播放，无需登录。
- **免费内置引擎**：内置微软 Edge readaloud 免费 WebSocket 端点，无需任何 API Key；
  支持多种中文音色（晓晓 / 晓伊 / 云健 / 云希 / 云扬 / 晓北）。
- **可选自定义端点**：后台可配置自定义合成端点（POST JSON → 音频字节），如自托管的
  OpenAI 兼容 /audio/speech 代理、piper 等，自带 Bearer Key 支持。
- **全文按哈希缓存**：同一正文 + 音色 + 语速只合成一次，磁盘缓存 60 分钟；
  缓存即文件系统，重启插件可复用，id 白名单防止路径穿越。
- **全局默认可配**：默认音色、默认语速、单次朗读最大字数均可后台设置。

## 安装方式

1. 后台「我的插件 → 上传 .bpk」安装启用；
2. 打开任意帖子详情页，正文下方出现「🔊 朗读」工具条；
3. 访客点击即开始朗读（自动使用站长配置的默认音色/语速）。

## 配置说明（后台「我的插件 → 朗读 → 设置」）

| 设置项 | 说明 | 默认 |
|---|---|---|
| 默认音色 | 站长默认朗读音色（可选 6 种中文音色） | `zh-CN-XiaoxiaoNeural` |
| 默认语速 | 合成语速（-20% ~ +20%） | `+0%` |
| 单次朗读最大字数 | 防止超长正文拖垮合成（上限 20000） | `3000` |
| 自定义合成端点 | 留空用内置免费引擎；填写则改走自定义（POST JSON `{text,voice,rate}` → 音频字节） | 空 |
| 自定义端点 API Key | 可选，配置后附加 `Authorization: Bearer` 头 | 空 |

## 常见问题

- **点朗读没声音**：确认插件为「运行中」状态；正文为空（如图片帖）会提示无文本可朗读。
- **提示文本过长**：正文超过「单次朗读最大字数」，可在设置调高。
- **想换音色**：后台修改「默认音色」保存后即时生效（重新朗读会按新参数重新合成）。
- **自定义端点格式**：POST JSON `{"text":"正文","voice":"音色","rate":"+0%"}`，
  响应体直接返回音频字节（MP3，Content-Type 建议 `audio/mpeg`）。

## 数据与隐私

- 正文仅发送到合成引擎（内置 Edge / 你配置的自定义端点）用于生成语音；
- 合成音频缓存在插件数据目录 `data/plugins/tts-reader/cache/`（60 分钟过期）；
- 插件不读取站点数据库、不写主进程任何状态，仅经宿主公开桥接取正文文本。
