# 图片 CDN

> 自动压缩与边缘分发，加速封面与灯箱加载。

## 功能特性

- **自动压缩**：上传即按场景压缩（封面 / 灯箱 / 缩略图多档位）；
- **边缘分发**：媒体资源走 CDN 加速，加载更快、源站压力更小。

## 安装

1. 后台「插件商城」搜索「图片 CDN」；
2. 点击「安装」并确认；
3. 无需额外配置，安装即生效。

## 适用场景

- 图片较多的摄影、旅行、美食类博客；
- 移动端访问占比高、在意首屏速度的站点。

## FAQ

**Q：已有媒体会自动迁移吗？**
A：不会。新上传的媒体自动接入；历史媒体可在后续版本中一键迁移。

**Q：压缩会损失画质吗？**
A：默认采用视觉无损档位，灯箱保留原图可查看。
