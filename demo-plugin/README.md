# 演示插件

> 月言插件开发演示：进程外隔离、钩子、自定义 API、许可证激活（demo_pro 功能）。

## 功能特性

| 能力 | 说明 |
|------|------|
| 进程外隔离 | 独立子进程运行，崩溃不影响主站 |
| 同步/异步钩子 | 演示 `comment.before_save` 等扩展点 |
| 自定义 API | `/api/v1/plugins/demo-plugin/ping` 等示例接口 |
| 许可证激活 | 付费功能开关 `demo_pro` 演示 |

## 安装

1. 后台「插件商城」搜索「演示插件」；
2. 点击「购买并安装 · ¥29」（开发环境模拟支付）；
3. 激活后在「我的插件」中查看许可证状态。

本插件面向插件开发者演示完整能力，源码与打包方式见：

## FAQ

**Q：如何验证 Pro 功能已激活？**
A：安装后访问 `/api/v1/plugins/demo-plugin/pro-status`（需登录），未激活返回降级状态。

**Q：可以免费体验吗？**
A：许可证有 7 天宽限期，超期未激活自动降级为 free 版。
