# Markdown 增强

> 代码高亮、目录、脚注与数学公式，写作更顺手。

## 功能特性

- **代码高亮**：主流语言语法高亮 + 行号；
- **目录**：根据标题自动生成文章目录（TOC）；
- **脚注**：文末注释引用；
- **数学公式**：LaTeX 公式渲染（行内 / 块级）。

## 安装

1. 后台「插件商城」搜索「Markdown 增强」；
2. 点击「安装」并确认，免费使用。

## 使用示例

````markdown
# 标题

代码高亮：

```go
func main() {
    fmt.Println("你好，月言")
}
```

数学公式：$E = mc^2$

脚注：这是一个引用[^1]。

[^1]: 脚注内容。
````

## 冲突说明

- 与 `markdown-legacy`（旧版 Markdown 渲染插件）**冲突**，不可同时安装，请先卸载旧版。

## FAQ

**Q：和默认编辑器冲突吗？**
A：不冲突。插件在渲染层增强，编辑器保持原样。

**Q：公式不显示？**
A：确认文章使用 `$...$` 包裹公式，并检查是否与旧版插件同时启用。
