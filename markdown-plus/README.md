# Markdown 增强

> 帖子正文展示增强：外链新窗口安全打开、图片懒加载、标题锚点定位。免费。

## 功能特性

- **外链安全**：`http(s)` 外链自动加 `target="_blank" rel="noopener noreferrer"`，站内相对链接不动；
- **图片懒加载**：`img` 自动补 `loading="lazy" decoding="async"`，长文加载更快；
- **标题锚点**：`h1-h6` 自动生成 `id`（文本 slug 化、同页唯一），可直达定位分享；
- **外链 nofollow**（可选，默认关）：防 SEO 外链权重流失。

## 安装

后台「插件商城」找到「Markdown 增强」→「免费安装」自动激活。

## 配置说明

| 设置项 | 说明 | 默认 |
|--------|------|------|
| 外链新窗口打开 | 加 target/rel 安全属性 | 开 |
| 图片懒加载 | loading=lazy | 开 |
| 标题锚点 | h1-h6 加 id | 开 |
| 外链 nofollow | 防 SEO 权重流失 | 关 |

## 技术说明

- 订阅 `content.render` 链式改写钩子（waterfall），与其他渲染插件可叠加；
- 全部增强幂等（已有对应属性的标签跳过），关闭开关后正文还原；
- 已有 `target`/`id` 的标签尊重作者手写，不重复添加。
