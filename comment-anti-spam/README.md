# 评论反垃圾

> 评论提交前多级反垃圾：黑名单词、外链拦截、AI 智能识别（可选），支持拒绝与留痕两种策略。免费。

## 功能特性

- **黑名单拦截**：自定义关键词（逗号或空格分隔），命中即处理；
- **外链拦截**：识别 `http(s)://`、`www.` 链接（可开关）；
- **AI 识别**（可选）：接入站点 AI 统一接口，语义级判定广告/灌水/诱导链接；
- **两种策略**：`block` 直接拒绝（评论者收到可读原因）/ `review` 放行并留痕。

## 安装

1. 后台「插件商城」找到「评论反垃圾」；
2. 点击「免费安装」自动激活（无需支付与许可证）。

## 配置说明

| 设置项 | 说明 |
|--------|------|
| 拦截策略 | `block` 直接拒绝 / `review` 放行并记录审计日志 |
| 拦截含外链评论 | 开启后含 URL 的评论命中处理（默认开） |
| 黑名单关键词 | 逗号或空格分隔，命中即处理 |
| AI 智能识别 | 需站点已配置 AI；失败自动放行（默认关） |
| AI 模型 | 留空用第一个可用模型 |

## 拦截策略对比

- **block**：适合小站点，无需专人值守；
- **review**：适合社区型站点——命中的评论照常展示，同时记录到 `data/plugins/comment-anti-spam/logs/audit.log` 供后台巡查。

## FAQ

**Q：AI 识别需要单独配置吗？**
A：不需要，插件复用站点「AI 统一接口」的设置；注意开启后评论提交会同步等待 AI 判定（秒级）。

**Q：AI 挂了会不会误伤评论？**
A：不会。AI 未配置、调用失败或返回无法解析时一律放行——反垃圾是增强能力，绝不阻断正常评论。
