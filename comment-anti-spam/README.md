# 评论反垃圾

> 智能识别垃圾评论与外链，保护讨论区干净有序。

## 功能特性

- **黑名单**：关键词 / 域名级拦截，命中即处理；
- **AI 识别**：接入站点 AI 统一接口，语义级判断垃圾倾向；
- **审核队列**：可疑评论进入人工审核，误杀可一键放行；
- **永久授权**：一次购买，终身可用（含功能更新）。

## 安装

1. 后台「插件商城」搜索「评论反垃圾」；
2. 点击「购买并安装 · ¥29」，按引导完成支付（开发环境为模拟支付）；
3. 支付成功后服务端自动签发许可证并激活 Pro 授权。

## 配置说明

| 设置项 | 说明 |
|--------|------|
| 拦截含外链评论 | 开启后含 URL 的评论默认拦截（默认开） |
| 黑名单关键词 | 逗号分隔的关键词列表，命中即拦截 |
| 拦截策略 | `block` 直接拦截 / `review` 转入审核队列 |

## 拦截策略对比

- **block**：适合小站点，无需专人值守；
- **review**：适合社区型站点，误杀率要求更低时选择。

## FAQ

**Q：AI 识别需要单独配置吗？**
A：不需要，插件复用站点「AI 统一接口」的设置，站点已配置模型即可工作。

**Q：被误杀的评论能找回吗？**
A：`review` 策略下进入审核队列可放行；`block` 策略建议先用关键词黑名单覆盖大部分场景。
