# 网易云音乐

站长登录网易云后，插件获取歌曲**真实播放地址**，前端**自研播放器**双主题播放，访客无需登录即可收听站内音乐。

## 功能特性

- **站长登录**：手机号 + 密码登录（eapi 加密，登录态 AES 加密落盘，重启自动恢复）
- **真实播放地址**：登录态获取歌曲 mp3 直链（免费歌匿名亦可获取）
- **自研播放器**：双主题适配的精美播放器（不再嵌套第三方 iframe）
- **搜索选歌**：发帖时搜索网易云歌曲插入

## 安装方式

1. 后台「插件商城」搜索「网易云音乐」安装，或本地上传 `.bpk`
2. 启用后访问「网易云音乐」侧栏入口（或 `/admin/plugin-pages/netease-music/settings`）
3. 用网易云手机号 + 密码登录

## 配置说明

| 配置项 | 说明 |
|---|---|
| 访客进入自动播放 | 开启后访客浏览帖子时自动播放（浏览器可能拦截，建议关闭） |
| 音质 | 播放音质：standard（标准）/ higher（较高）/ exhigh（极高） |

## FAQ

- **为什么有些歌播放不了？** 无版权 / 需会员的歌曲，网易云接口不返回播放地址，会提示「无版权或需会员」。
- **播放地址会失效吗？** 地址有效期约 20 分钟，插件按需实时获取，无需担心。
- **访客需要登录吗？** 不需要，只有站长在后台登录一次。
