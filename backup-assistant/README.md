# 备份助手

> 定时导出内容与媒体，支持云端与本地双通道。

## 功能特性

- **定时导出**：按日 / 周 / 月自动导出帖子与评论；
- **云本地双通道**：本地备份 + 云端存储双保险；
- **一键恢复**：备份包可一键恢复站点数据。

## 安装

1. 后台「插件商城」搜索「备份助手」；
2. 点击「购买并安装 · ¥19」，完成支付后自动激活。

## 配置说明

| 设置项 | 说明 |
|--------|------|
| 备份频率 | 每日 / 每周 / 每月 |
| 备份通道 | 本地 / 云端 / 双通道 |
| 保留份数 | 超出自动清理最旧备份 |

## FAQ

**Q：备份包含哪些数据？**
A：帖子、评论、媒体文件与站点设置，不含密钥类敏感信息。

**Q：云端通道支持哪些存储？**
A：当前版本为本地通道；云端通道随版本更新逐步开放。
