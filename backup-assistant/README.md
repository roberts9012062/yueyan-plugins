# 备份助手

> 媒体库定时/手动备份：ZIP 打包落盘 + 保留策略自动清理 + 完成通知 webhook（云端通道）。免费。

## 功能特性

- **手动备份**：后台「备份助手」页一键 ZIP 打包媒体库；
- **定时备份**：每天 / 每周自动执行（设置变更无需重启，到点巡检自动生效）；
- **保留策略**：超出保留份数自动清理最旧备份（默认 5 份）；
- **云端通知**：备份完成后 POST 元信息（文件名/大小/时间）到自定义 webhook，可对接网盘、群机器人等。

## 安装

1. 后台「插件商城」找到「备份助手」；
2. 点击「免费安装」自动激活（无需支付）。

## 配置说明

| 设置项 | 说明 |
|--------|------|
| 定时备份 | off 关闭 / daily 每天 / weekly 每周 |
| 保留份数 | 超出自动清理最旧（默认 5） |
| 通知 webhook | 备份完成后 POST 元信息，留空不通知 |

## 后台页面

侧栏「插件 → 备份助手」进入仪表页：调度状态、上次备份时间、立即备份按钮与备份历史列表。

## FAQ

**Q：备份包含哪些数据？**
A：媒体库文件（`data/media` 目录，ZIP 保留相对结构）；帖子/评论数据请使用后台自带的「备份导出」。

**Q：云端通道怎么用？**
A：配置 webhook 后，每次备份完成会把元信息推送到该地址，由接收端（网盘机器人、运维脚本等）决定转存方式。
