# SEO 优化

> 发帖 SEO 面板（标题 / 描述 / URL 别名 / 收录策略）+ 元信息校验，一键提升收录。

## 功能特性

| 能力 | 说明 |
|------|------|
| 站点地图 | 自动生成 `sitemap.xml`，覆盖全站公开帖子 |
| 元信息 | 帖子级标题、描述、关键词校验与回写 |
| Open Graph | 分享卡片标题 / 描述 / 默认 OG 图 |
| robots.txt | 收录策略控制（允许 / 禁止索引） |
| 发帖 SEO 面板 | 编辑器侧栏实时评分，发布前即纠偏 |

## 安装

1. 后台进入「插件商城」，搜索「SEO 优化」；
2. 点击「安装」并确认；
3. 安装完成后自动启用，侧栏出现「SEO 优化」设置入口。

## 配置说明

| 设置项 | 说明 |
|--------|------|
| 站点标题后缀 | 全站标题统一后缀，如 `· 月言` |
| 自动生成 sitemap | 开关，默认开启 |
| 默认 OG 图 | 无封面帖子的分享默认图（可留空） |

## 适用场景

- 个人博客希望文章更快被搜索引擎收录；
- 需要统一分享卡片的观感；
- 想在发布前检查 SEO 元信息是否完整。

## FAQ

**Q：安装后 sitemap 在哪里？**
A：`https://你的站点/sitemap.xml`，公开可访问，建议提交到搜索引擎站长平台。

**Q：URL 别名怎么用？**
A：发帖面板中可为帖子设置短别名，前台通过 `/p/{别名}` 跳转，便于分享与收录。
